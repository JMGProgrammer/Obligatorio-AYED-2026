# Estudio para la defensa — Obligatorio AYED 2026 (NovaTech)

Carpeta de estudio creada a partir del ejercicio `Ejercicio-Arbol-Nario` y de la
documentación del obligatorio. Objetivo: dominar el árbol N-ario y la
recursividad para que el profesor vea que sabemos de sobra y nos haga como
máximo 2 preguntas.

## Orden de estudio sugerido

1. [`01-Conceptos-clave.md`](01-Conceptos-clave.md) — qué es un árbol N-ario y su vocabulario.
2. [`02-Por-que-funciona.md`](02-Por-que-funciona.md) — por qué esta estructura y por qué termina.
3. [`03-Como-funciona-paso-a-paso.md`](03-Como-funciona-paso-a-paso.md) — cómo crear el nodo, insertar, recorrer.
4. [`04-Preguntas-del-profesor.md`](04-Preguntas-del-profesor.md) — preguntas típicas con respuesta lista.
5. [`05-Preguntas-avanzadas-para-dominar.md`](05-Preguntas-avanzadas-para-dominar.md) — para lucirse y acortar la defensa.
6. [`06-Checklist-defensa.md`](06-Checklist-defensa.md) — verificación final.

## Regla de oro de la defensa

> No es suficiente ejecutar opciones. Cada integrante debe poder explicar
> qué sucede **internamente**: caso base, paso recursivo, referencias, niveles.

Si demostramos eso desde el primer minuto, el profesor reduce las preguntas.
