El enunciado solicita capturas de las funcionalidades principales. Las imágenes deben obtenerse ejecutando el programa real del grupo.

## Contenido de cada captura

### 01 — Menú principal

Debe mostrar las seis secciones del sistema.

### 02 — Organigrama completo

Debe mostrar:

- indentación;
- niveles;
- cargos;
- subordinados totales.

### 03 — Búsqueda

Buscar el legajo `1003` y mostrar a Martín Silva.

### 04 — Conteo

Consultar el legajo `1001`. El resultado esperado es 5.

### 05 — Masa salarial

Consultar el legajo `1001`. El resultado esperado es 683000.

### 06 — Cadena de mando

Consultar el legajo `1003`:

```text
Martín Silva <- Ana Rodríguez <- Diego Pérez <- Laura Méndez
```

### 07 — Nivel

Consultar nivel 2.

### 08 y 09 — Reasignación

Tomar una captura antes y otra después de mover un empleado. Debe observarse el cambio de posición y nivel.

### 10 — Prevención de ciclo

Intentar una reasignación inválida y mostrar el rechazo.

### 11 — Proyectos

Mostrar los dos proyectos, sus estados y horas.

### 12 — Asignaciones

Mostrar las asignaciones precargadas y las horas totales del proyecto 1.

## Inserción en Markdown

Después de guardar las imágenes pueden incluirse así:

```md
![Organigrama completo](capturas/02-organigrama-completo.png)
```

## Recomendaciones visuales

- Maximizar la terminal o utilizar un tamaño legible.
- Evitar que aparezcan rutas o ventanas irrelevantes.
- Utilizar un tema con buen contraste.
- No recortar información necesaria para interpretar el resultado.
- Reiniciar el programa antes de repetir una demostración que modifica datos.

## Estado

Las capturas permanecen pendientes hasta que el grupo ejecute el programa y genere evidencia real. No deben sustituirse por resultados inventados.
